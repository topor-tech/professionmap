# Техническое задание: Платформа для трудоустройства и стажировок

## 1. Обязательный функционал

### 1.1 Роли пользователей
- **Администратор ОЭЗ** - управление платформой и модерация
- **HR компании** - публикация вакансий и работа с соискателями  
- **Представитель вуза** - подача заявок на стажировки
- **Соискатель** - просмотр вакансий и отклики (упрощённый кабинет)

### 1.2 Основные функции
- Формы создания вакансий и заявок на стажировку
- Публичный каталог для просмотра без авторизации
- Механизм отклика для соискателей
- Панель модерации для администратора ОЭЗ

## 2. Требования

### 2.1 Пользовательский интерфейс
- Интуитивно понятный и современный интерфейс

### 2.2 Техническая реализация
- Качество кода
- Архитектура
- Использование современных технологий

### 2.3 Масштабируемость
- Возможность легко добавлять новый функционал в будущем

## 3. Сценарии использования

### 3.1 Сценарий 1: HR-компании публикует вакансию

1. HR авторизуется на платформе
2. Переходит в раздел «Мои вакансии»
3. Нажимает «Создать вакансию»
4. Заполняет форму:
   - Должность
   - Описание
   - Требования
   - Контакты
5. Вакансия отправляется на модерацию ответственному сотруднику ОЭЗ
6. После одобрения вакансия публикуется в общем каталоге
   - Возможность установить таймер для автоснятия с публикации
7. Представители HR видят резюме соискателей на свои вакансии
8. Доступ к банку общих резюме с дополнительными правами

### 3.2 Сценарий 2: Соискатель откликается на вакансию

1. Соискатель просматривает каталог вакансий
2. Находит подходящую и нажимает «Откликнуться»
3. Система предлагает:
   - Загрузить резюме (файл)
   - Заполнить анкету (упрощённое резюме прямо на платформе)
4. Резюме/анкета мгновенно и автоматически поступает в личный кабинет HR указанной компании

### 3.3 Сценарий 3: Представитель вуза размещает заявку на стажировку

1. Авторизация
2. Раздел «Стажировки» → «Подать заявку»
3. Заполняет форму:
   - Специальность
   - Количество студентов
   - Период
4. Заявка поступает в общий каталог стажировок для компаний
5. Представителям компаний направляется уведомление о новом резюме, соответствующем их требованиям (если работодатель отметил ставку актуальной в своём личном кабинете)

## 4. Возможности для модератора ОЭЗ

- Формирование настраиваемой статистики
- Выгрузка статистических данных
- Хранение базы данных (контакты, резюме и т.д.)
- Пополнение базы рассылок по данной ЦА (интеграция с сервисом рассылок)
